# Project Memory

## Core
Aldi: postpartum symptom app. All UI copy Russian, address as "Вы", use user's strings exactly. Page title always just "Aldi"; no medical words in titles/URLs/history.
Patient side: calm night room, ivory + lavender, one breathing sphere. No pink/blue, babies, faces, avatars, body illustrations, stock photos. Never diagnose.
Doctor side: cool dense black-on-white clinical, prints on A4. Never blend styles.
Build in stages, wait for approval: design system → patient screens → doctor cabinet.
Show "Не указано" for missing, "⚠ Проверьте" for uncertain; every card line backed by patient's quote.
